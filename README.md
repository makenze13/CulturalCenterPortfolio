## Культурный центр "Успех"

Система управления культурным центром на C# и .NET 8

Учебный проект для автоматизации работы культурного центра: управление мероприятиями, организаторами, сотрудниками и пользователями, работа с билетами и взаимодействие клиентских приложений с общей базой данных.

## Технологии

C# 12/ .NET 8

ASP.NET Core Web API — серверная логика и работа с данными

ASP.NET Core MVC — клиентский веб-сайт

WPF — настольное приложение

Entity Framework Core — работа с базой данных

PostgreSQL — хранение данных

HTML / CSS / JS — оформление веб-интерфейса

## Возможности

**Веб-сайт:**

Просмотр каталога мероприятий.

Фильтрация мероприятий по категориям.

Регистрация и авторизация пользователей.

Покупка билетов.

Личный кабинет пользователя и просмотр билетов.

**Настольное приложение:**

Разделение обязанностей сотрудников по ролям: менеджер, кассир, администратор.

Менеджер: CRUD-операции с организаторами, мероприятиями и сотрудниками.
Кассир: поиск, фильтрация и просмотр мероприятий, продажа билетов, печать чеков.
Администратор: CRUD-операции с пользователями, сброс паролей, настройка подключения приложения к API.

**Web API:**

Получение, добавление, изменение и удаление данных.

Взаимодействие с PostgreSQL через Entity Framework Core.

Разделение контроллеров, моделей и сервисов.

Обработка HTTP-запросов и возврат данных клиентским приложениям.

## Архитектура:

Проект состоит из трёх приложений:

CulturalCenterApi

ASP.NET Core Web API — серверная часть

CulturalCenterWeb

ASP.NET Core MVC — веб-интерфейс для клиентов

CulturalCenterWpf

WPF — настольное приложение

## Взаимодействие компонентов:

Клиентские приложения → Web API → Entity Framework Core → PostgreSQL.

API выступает связующим звеном между клиентскими приложениями и базой данных.

## База данных

SQL-скрипт `CulturalCenterDatabase.sql` содержит структуру базы данных PostgreSQL.
